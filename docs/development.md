# 开发方向

规则以根目录 [Rules.md](../Rules.md) 为准。

## 当前阶段

旧实现已整体移入 `legacy/`，仅供运行和参考，其规则存在已知偏差。
新包位于 `src/guaguadeng/`，目前仅建立包入口，尚未实现新游戏。
历史需求保留在 `legacy/ai-prompt.md`，其中类设计、无 GUI 等设想不再作为约束。

## 职责规划

按实现进度创建模块，不预先建立空目录：

- `domain/`：卡牌、玩家与回合状态、合法性、判胜和计分。
- `engine/`：统一处理出牌动作，推进轮、局和场，保证失败不改变状态。
- `strategies/`：从合法动作中选择，供 AI、提示和托管复用。
- `ui/`：展示与交互，不修改规则状态；界面技术待选定。

## 后续顺序

1. 在 `docs/rule_examples.md` 整理规则案例及预期结果。
2. 实现规则模型和对应测试，覆盖拆牌、配型优先、管牌与无法压牌等边界。
3. 实现引擎，验证完整一局、牌数守恒和结算唯一性。
4. 完成新界面，再增强策略与动画。

新代码不依赖或导入 `legacy/`。旧版稳定保留到新实现可用，再决定移除。
