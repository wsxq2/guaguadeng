# 刮刮登离线网页版

`index.html` 是自包含的离线游戏文件，不需要安装 Python、联网、服务器或其他资源。在支持打开本地 HTML 文件的浏览器中打开即可；可以将这一个文件复制到手机。部分 Android 浏览器或文件管理器可能限制直接打开本地 HTML，需要选择能打开 HTML 的浏览器或文件管理器。

南方为玩家，其余三方由电脑操控。点击手牌选择，再点击“出牌”；“提示”选择一组合法牌。完整局结束后可以继续下一局，结束本场时未完成局不计分。进度尽力保存在当前浏览器本地存储中；本地文件的存储支持因浏览器而异，清除数据、换浏览器或移动文件可能导致进度不可用。

运行离线引擎测试：`node web/tests/game.test.cjs`。规则参考仓库根目录 Rules.md 与 Python 引擎。
