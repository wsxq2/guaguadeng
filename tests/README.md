# 测试

新实现的测试放在此目录，目前尚无自动化测试。

以根目录 [Rules.md](../Rules.md) 为规范，不以旧实现作为正确性标准。
直接使用测试表达规则案例，不另建规则示例文档。

## 工作方式

- 按小步 TDD 推进：先写测试，确认因目标行为未实现而失败，再实现并重构。
- 用参数化案例表达具体手牌、轮内出牌记录、待提交牌和预期结果。
- 同时覆盖合法出牌与应拒绝的出牌，验证失败原因及失败后状态不变。
- 测试公开行为，避免依赖私有方法、内部调用顺序或 GUI。
- 随机发牌和完整对局测试使用可复现的随机源。

实施顺序和模型职责见 [开发说明](../docs/development.md)。
