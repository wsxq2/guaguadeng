# 刮刮登纸牌游戏

一个使用Python实现的4人纸牌游戏，支持1个真实玩家和3个AI玩家。

## 游戏规则

- **牌组**: 40张牌，4个花色，每花色1-10点
- **玩家**: 4人，位于东南西北四个方位
- **发牌**: 每人10张牌
- **庄家**: 随机选出，后续逆时针轮换
- **出牌规则**:
  - 领牌者（回合第一个出牌）：可出1-4张相同点数的牌
  - 跟牌者：必须出相同数量的牌
    - **递增规则**：后出牌者必须出比前面玩家更大的点数
    - 没有更大的牌时，可以随意出牌
    - 优先出相同点数的牌，不够时可混合出牌
  - **第3个出牌者必须管牌**：
    - 正常情况：出8点以上且比前面玩家大的牌
    - 无法管牌时：按优先级出尽量大的牌
      1. 优先出较少相同牌配合单张（如2张相同+1张单张）
      2. 其次出多张最大的单牌
- **胜负**: 每回合最大点数获胜（10>9>...>2>1）
  - 如有多个玩家出相同最大点数，先出牌者获胜
  - **特殊规则**：当领牌者出多张相同牌时，多张相同牌优于多张不同牌
- **获牌**: 胜出者获得自己出的牌
- **计分**: 4×获得牌数-10

## 游戏操作

### 命令行版本
1. 按Enter键开始游戏
2. 庄家会自动选出并洗牌
3. 查看手牌并选择出牌方案
4. 输入数字选择出牌
5. 游戏结束后可选择继续下一局

### 图形界面版本
1. 点击"开始游戏"按钮
2. 点击手牌选择要出的牌（高亮显示）
3. 点击"确认出牌"完成出牌
4. 观察AI玩家自动出牌
5. 游戏结束后自动显示排名

> 📖 详细的图形界面使用说明请查看 [GUI_GUIDE.md](GUI_GUIDE.md)
6. 随时输入'q'退出游戏

## 类设计

### Card类
- `value`: 牌的点数(1-10)
- `suit`: 牌的花色(♠♥♦♣)
- `create_deck()`: 创建完整牌组

### Player类
- `score`: 玩家分数
- `position`: 玩家位置(东南西北)
- `hand_cards`: 手中的牌
- `won_cards`: 获胜的牌
- `play_cards()`: 出牌方法
- `calculate_score()`: 计算得分

### Game类
- `start_new_game()`: 开始新游戏
- `deal_cards()`: 发牌
- `play_game()`: 游戏主循环
- `determine_round_winner()`: 判断回合胜者

## 特性

### 特殊规则说明

- **管牌规则完善**：第3个出牌者必须管牌（出≥8点且比前面大的牌），但同时也要遵守递增点数规则
- **管牌优先级**：当前面最大点数≥8点时，优先满足管牌要求（≥8点）
- **递增点数优先**：当前面最大点数<8点时，优先满足递增点数要求
- **无法管牌时**：当递增点数要求使得无法管牌时（如前面出了10点），可以随意出牌
